# Public snapshot assets

The snapshot retains Shedmo-owned branding supplied by the project owner at `assets/shedmo-icon.png`. The same artwork is used for the native icon, splash configuration, and web favicon.

Bundled Outfit font files retain their upstream `OFL.txt`. Inter and Expo vector icons are installed through package dependencies and retain their package/upstream licenses. No application-wide license is granted by these dependency licenses.

Unused template artwork and unverified third-party photo references are excluded. Synthetic prototype fixture records remain, with empty photo URLs rendered through the existing image fallback. No user-uploaded photographs or private screenshots are included.
